## Обзор проекта

Система "Бизнес Жардамчы ГО" (Business Assistant GO) - это мост между клиентами в WhatsApp и исполнителями в Telegram для города Шамалды-Сай.

## Потоки данных

### Заказ в Кафе
1. Клиент пишет в WhatsApp
2. Система создает заказ в БД
3. Заказ отправляется в Telegram группу кафе
4. Кафе принимает заказ (кнопка)
5. Клиент получает подтверждение
6. Автоматически создается заявка на доставку в группу такси

### Заказ в Магазин
1. Клиент отправляет список покупок
2. Список отправляется закупщику в ЛС
3. Закупщик берет заказ
4. Клиент получает подтверждение
5. Закупщик закупает и доставляет

### Заказ в Аптеку
1. Клиент отправляет название лекарства или фото рецепта
2. Запрос отправляется в группу аптек
3. Аптеки предлагают цены
4. Клиент получает предложение с ценой
5. Клиент подтверждает/отменяет
6. При подтверждении - заявка в группу такси для доставки

### Заказ Такси
1. Клиент указывает маршрут
2. Заявка мгновенно отправляется в группу таксистов
3. Таксист берет заказ (первый успевший)
4. Списывается комиссия (если не Рамазан)
5. Клиент получает данные водителя

### Заказ Портера
1. Клиент описывает груз и маршрут
2. Заявка отправляется в группу портеров
3. Водитель берет заказ
4. Клиент получает данные водителя

## Комиссии и тарифы

| Услуга | Комиссия | Примечание |
|--------|----------|------------|
| Кафе | 5% | От суммы заказа |
| Аптека | 5% | От суммы заказа |
| Такси | 10 сом | Фиксированная (0 в Рамазан) |
| Портер | 40 сом | Фиксированная |

## Таймауты

| Услуга | Таймаут | Действие при таймауте |
|--------|---------|----------------------|
| Кафе | 5 минуты | Повышенный приоритет заказа |
| Аптека | 5 минуты | Напоминание в группу |
| Такси | 1 минута | Повышенный приоритет |

## API Endpoints

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/whatsapp_webhook` | POST | Прием сообщений от WhatsApp |
| `/telegram_webhook` | POST | Прием callback от Telegram |
| `/health` | GET | Проверка работоспособности |

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
```bash
cp .env.example .env
# Отредактируйте .env
```

### 3. Настройка Google Sheets
- Создать проект в Google Cloud Console
- Включить Google Sheets API
- Создать Service Account
- Скачать credentials.json
- Создать таблицу и дать доступ сервисному аккаунту

### 4. Настройка Telegram Bot
- Написать @BotFather
- Создать бота
- Получить токен
- Добавить бота в группы
- Получить ID групп

### 5. Настройка WhatsApp (GREEN API)
- Зарегистрироваться на green-api.com
- Создать инстанс
- Получить ID и токен
- Авторизоваться по QR-коду

### 6. Запуск
```bash
# Разработка
python src/app.py

# Продакшен
./deploy.sh production
```

### 7. Настройка cron
```bash
./setup_cron.sh
```
