# Жардамчы ГО (Jardamchy GO)

**Автоматизированная платформа городских услуг с ИИ-ботом для приёма заказов через WhatsApp и диспетчеризацией исполнителей через Telegram.**

---

## Обзор системы

**Жардамчы ГО** — мультисервисная платформа для города Шамалды-Сай, объединяющая заказ еды, доставку продуктов, поиск лекарств, вызов такси и грузоперевозки в единую экосистему. Клиенты оформляют заказы через WhatsApp-бот с NLU на базе GPT-4.1-mini, заказы автоматически распределяются по профильным Telegram-группам исполнителей, а администраторы управляют системой через веб-панель с аналитикой в реальном времени.

## Ключевые возможности

### 🤖 AI-боты

#### WhatsApp-бот (клиентский)
- Приём заказов на естественном языке (русский / кыргызский / смешанный)
- NLU на базе **OpenAI GPT-4.1-mini** — извлечение интента, адресов, деталей заказа
- **Speech-to-Text** — голосовые сообщения распознаются через OpenAI Whisper
- Детерминированный **state-machine** с 20+ состояниями для пошагового оформления заказа
- Отправка интерактивных кнопок для выбора услуг и подтверждения
- Фолбэк-логика на ключевых словах при недоступности GPT
- Валидация адресов: отклонение слишком общих адресов («дом», «уйго»)
- Возможность отмены заказа на любом этапе

#### Telegram-бот (исполнители)
- Регистрация водителей/портеров/муравьёв через пошаговый диалог
- Inline-кнопки в группах: «Взять заказ», «Приехал», «Готовность N мин»
- Команды: `/register`, `/balance`, `/profile`, `/stats`, `/help`
- Проверка баланса и профиля через личные сообщения

#### 6 типов услуг
| Услуга | Описание | Группа |
|--------|----------|--------|
| 🍔 **Кафе** | Заказ еды с доставкой | `GROUP_CAFE_ID` |
| 🛒 **Магазин** | Закупка и доставка продуктов | `GROUP_SHOP_ID` |
| 💊 **Аптека** | Поиск лекарств с аукционом цен | `GROUP_PHARMACY_ID` |
| 🚖 **Такси** | Вызов такси по маршруту | `GROUP_TAXI_ID` |
| 🚛 **Портер** | Крупные грузоперевозки | `GROUP_PORTER_ID` |
| 🐜 **Муравей** | Мелкие грузы (желмаян) | `GROUP_ANT_ID` |

### 🧭 Диспетчеризация

- Заказы маршрутизируются в профильные Telegram-группы по типу услуги
- Inline-кнопка **«Взять заказ»** — логика **first-click-wins** с атомарной проверкой в БД
- Аукционная система для кафе: 2 минуты на отклик с указанием времени готовности
- Аукцион цен для аптек: 3 минуты на отправку цены, клиент выбирает лучшую
- Срочные заказы: по истечении таймаута заказ помечается `URGENT` и переотправляется
- При принятии заказа такси — кнопка **«Приехал»** отправляет уведомление клиенту в WhatsApp
- Магазин:Такси может за вас доставить продукты

#### Статусы заказов
```
PENDING → AUCTION → ACCEPTED → READY → IN_DELIVERY → COMPLETED
                                                     → CANCELLED
                                          → URGENT (по таймауту)
```

### 💳 Биллинг и балансы

| Услуга | Комиссия | С кого |
|--------|----------|--------|
| Такси | 10 сом (фикс.) | Водитель |
| Кафе | 5% от суммы заказа | Кафе (долг) |
| Аптека | 5% от суммы | Аптека |
| Портер | 20 сом | Портер |
| Муравей | 10 сом | Муравей |
| Закупщик | 10 сом | Закупщик |
| Такси (доставка из магазина/аптеки) | 10 сом | Водитель |

- **Внутренние счета водителей** — баланс отслеживается в БД, пополняется администратором
- **Минимальный баланс** — 10 сом для приёма заказов (проверка при нажатии «Взять заказ»)
- **Автосписание** комиссии при принятии заказа
- **Режим Рамазан** — глобальный переключатель, отключающий комиссию с таксистов
- **Долг кафе** — накопительная комиссия, максимальный лимит 10 000 сом
- Все операции логируются в таблицу `transactions`

### 🗄 Хранение данных

**PostgreSQL** с пулом соединений (`ThreadedConnectionPool`, до 10 соединений).

#### Таблицы базы данных

| Таблица | Назначение |
|---------|-----------|
| `users` | Клиенты WhatsApp (телефон, состояние, temp_data, язык) |
| `orders` | Заказы (тип, статус, клиент, детали, адрес, цена, комиссия) |
| `drivers` | Водители (telegram_id, тип, баланс, авто, госномер, блокировка) |
| `cafes` | Кафе (telegram_id, название, адрес, долг, комиссия) |
| `pharmacies` | Аптеки (telegram_id, название, адрес) |
| `shoppers` | Закупщики (telegram_id, баланс) |
| `transactions` | Лог всех финансовых и системных операций |
| `auction_timers` | Таймеры аукционов с TTL и привязкой к сообщению |
| `pharmacy_bids` | Ценовые предложения аптек на заказ |
| `telegram_sessions` | Сессии Telegram-пользователей (регистрация водителей) |

Индексы оптимизируют выборку по статусу заказов, клиентам, транзакциям и таймерам аукционов.

Опциональная интеграция с **Google Sheets** для легаси-данных и бэкапа (учётные данные сервисного аккаунта).

### 🌐 Админ-панель

**SPA** на чистом HTML/CSS/JS, доступная по маршруту `/admin/panel`.

#### Функциональность

- **Дашборд** — метрики за день/неделю/месяц/всё время: заказы, выручка, комиссия, разбивка по услугам, график по дням
- **Управление заказами** — фильтрация по статусу, типу услуги, периоду; пагинация; детали заказа
- **Водители** — CRUD, фильтр по типу, статистика заказов каждого водителя, пополнение/списание баланса
- **Кафе** — управление, просмотр долга
- **Аптеки** — добавление/удаление
- **Закупщики** — управление закупщиками
- **Пользователи** — список WhatsApp-клиентов с количеством заказов
- **Транзакции** — полная история операций
- **Рассылка** — отправка сообщений водителям, кафе, аптекам, закупщикам и в Telegram-группы
- **Настройки** — просмотр комиссий, переключение режима Рамазан

### Фоновые задачи

Фоновый планировщик запускается в отдельном потоке, проверяет таймауты каждые 30 секунд:

| Задача | Таймаут | Действие |
|--------|---------|----------|
| Кафе аукцион | 2 мин | Пометить как `URGENT`, переотправить |
| Аптека ответ | 3 мин | Выбрать лучшую цену, уведомить клиента |
| Такси (незабранный) | 5 мин | Удалить сообщение из группы, отменить |
| Такси (забранный) | 30 мин | Удалить Telegram-сообщение «заказ забран» |

## Поток обработки заказа

Пример: заказ такси.

```
1. Клиент отправляет сообщение в WhatsApp:
   "Такси с базара на Ак-Булак"

2. GREEN API пересылает webhook на /whatsapp_webhook

3. main.py получает сообщение, загружает пользователя из БД
   Состояние: IDLE → вызов nlu.py

4. nlu.py отправляет запрос в GPT-4.1-mini:
   → Извлекает: intent=taxi, from="базар", to="Ак-Булак"

5. Пользователю отправляется сообщение подтверждения:
   "🚖 Откуда: Базар → Куда: Ак-Булак. Подтверждаете?"

6. Клиент отвечает "Да"
   → nlu.py подтверждает (parse_confirmation)

7. Заказ создаётся в БД (статус PENDING)
   → Формируется Telegram-сообщение с inline-кнопкой "Взять заказ"
   → Отправляется в GROUP_TAXI_ID

8. Водитель в Telegram нажимает "Взять заказ"
   → telegram_handler.py проверяет:
     - Заказ ещё не занят (first-click-wins)
     - Водитель активен и не заблокирован
     - Баланс ≥ 10 сом
   → Списывается комиссия 10 сом
   → Статус заказа → ACCEPTED
   → Сообщение в группе обновляется: "✅ ЗАКАЗ ЗАБРАН: <Имя водителя>"

9. Клиент получает WhatsApp-уведомление:
   "Ваш заказ принят! Водитель: Иванов, Toyota Camry, 04 123 AA"

10. Водитель нажимает кнопку "Приехал"
    → Клиент получает: "Водитель приехал! Выходите."
